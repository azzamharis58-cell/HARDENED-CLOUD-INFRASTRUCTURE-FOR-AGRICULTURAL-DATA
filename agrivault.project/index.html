How AgriVault Works

Technical overview of the encryption pipeline

Key Concepts
🔑
Key Derivation (PBKDF2-HMAC-SHA256)
Your password is never used directly as a key. PBKDF2 runs 310,000 SHA-256 iterations with a random 32-byte salt, producing a 256-bit AES key. This makes brute-force attacks computationally infeasible.
🔐
AES-256-CBC Encryption
Files are encrypted using AES with a 256-bit key in CBC (Cipher Block Chaining) mode. A random 16-byte IV (Initialization Vector) is generated for each file, ensuring that two encryptions of the same file produce completely different ciphertext.
🛡️
Encrypt-then-MAC (HMAC-SHA256)
After encryption, HMAC-SHA256 is computed over the ciphertext. During decryption, the HMAC is verified BEFORE decrypting — this prevents padding oracle attacks and detects any file tampering.
🗂️
AgriVault (.agv) File Format
Each encrypted file uses the custom .agv format: MAGIC(12) | SALT(32) | IV(16) | HMAC(32) | TIMESTAMP(8) | FILENAME_LEN(2) | FILENAME | CIPHERTEXT. The original filename is preserved inside the encrypted blob.
Why This Matters for Agriculture
Agriculture data includes highly sensitive information: crop yield projections, soil composition, irrigation schedules, pesticide usage records, financial reports, and proprietary seed/breeding data. A data breach could expose competitive intelligence, violate GDPR/data protection laws, and damage farmer livelihoods. Encrypting data at rest — even on a trusted cloud drive — ensures that a storage breach does not expose readable data.

Flask API Endpoints

Available Routes
POST
/api/upload
Upload & encrypt a file. Body: multipart/form-data with file and password fields.
GET
/api/files
List all files in vault (metadata only — no ciphertext exposed).
POST
/api/download/:id
Decrypt and download file. Body: JSON with password. Returns 401 on wrong password.
DELETE
/api/delete/:id
Securely wipe a file (overwrite with random bytes before deletion).
GET
/api/stats
Vault statistics: file count, total original vs encrypted bytes.
